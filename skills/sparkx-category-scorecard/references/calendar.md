# Calendar (US default; exact dates change yearly - write "date not confirmed" rather than guess)

| Event | US window |
|---|---|
| New Year resolutions | Jan 1-15 |
| Valentine's Day | Feb 14 |
| Prime Big Spring Sale | late March |
| Mother's Day | 2nd Sunday of May |
| Prime Day | July |
| Back to school | Jul-Aug |
| Prime Big Deal Days | early-mid October |
| Black Friday to Cyber Monday | 2026: Nov 27-30 |
| Holiday shipping cut-off -> Christmas | ~Dec 18-25 |

Pass the next event as `--event "NAME|START|END"` with `--today`.

Timing rule: from 7 days before the start through the last day - including while the event is running - this skill
plans only: no budget lowering and no writes. Promotion budgets go to sparkx-promo-prep (before) and
sparkx-promo-monitor (during). Budget moves resume the day after the event ends; judge them on settled days after that.
