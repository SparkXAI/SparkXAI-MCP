# Which skill?

| The question | Skill |
|---|---|
| How do my categories compare with the market and peers? Where should the budget go? What ROAS / ACOS goal is fair? | **sparkx-category-scorecard** (this skill) |
| One category: which searches to bid up or down, new keywords, price / pack; SQP audit; why share or sales dropped | sparkx-sqp-insight (plan mode for one category) |
| One SQP or peer number, or reading peer rows for a target | sparkx-query-market-data |
| Week-over-week or month-over-month recap, why a number moved | sparkx-weekly-ads-report / sparkx-monthly-ads-report |
| One named ASIN | sparkx-asin-deep-dive |
| Spend and efficiency by ad type, site, portfolio, weekday | sparkx-ads-structure-analysis |
| Product tiers and lifecycle (star / core / long tail) | sparkx-product-diagnosis |
| Search-term negatives and harvesting | sparkx-search-term-diagnosis |
| Budgets and bids for a promotion, before or during it | sparkx-promo-prep / sparkx-promo-monitor |
| Writing the confirmed daily budgets | sparkx-edit-ads (`campaign` + `updateBudget`) |
| Budget or target of an AI managed group | sparkx-edit-ai-group |

This skill changes only campaign daily budgets (through sparkx-edit-ads). Search-level bids and targets belong to
sparkx-sqp-insight. Do not add the sales estimates of the two together: a budget raise and a bid raise on the same
campaign buy partly the same clicks.
